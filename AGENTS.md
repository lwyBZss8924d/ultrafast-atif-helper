# ultrafast-atif-helper

Read [SPEC.md](SPEC.md) and select one resource through [llms.txt](llms.txt).
Complete authorized changes, useful checks and delivery; preserve unrelated work.

This MIT fork retains fast-jev-compaction attribution and source. New local ETL,
retrieval and context-view behavior belongs in `src/helper/`. Inactive upstream
plugin discovery files stay under `upstream-reference/`; do not reactivate the
legacy remote compaction Hook while installing this package.

Preserve original bytes, literal ATIF versions and exact source evidence. Never
invent native session/turn IDs from an ATIF container, a path, or another record's
context. Unknown versions and extras remain explicit. Ambiguous call/result
relationships are conservatively retained. A retention probability is not deletion
authority, task acceptance or an evaluated reward.

Use `npm run build`, `npm run typecheck` and `npm test` for changed runtime code;
retain original failure fixtures and proportionate regression checks. Public
packaging additionally runs `python3 scripts/distribution/test_package.py` and
`python3 scripts/distribution/package.py check`. Live provider quality requires
separate frozen data, criteria, model identity, attempt budget and receipts.

Ship self-contained Skills, CLI/API, agent navigation, plugin manifests and
reviewable CI/release artifacts. The recorder may bundle a pinned helper version;
keep each repository's identity, commits, licenses and tests distinct.

Keep real trajectories, selected-source datasets and private evidence under
ignored `.local/` or `workspace/`. Public fixtures are synthetic. No account homes,
credentials, real native IDs or maintainer paths belong in public source. Optional
scoring takes separately prepared synthetic/redacted inputs; deterministic ETL
must not automatically transmit its source. Transport success is not score quality.

Close intended source with an owner checkpoint, commit, machine-readable PoUW note
under `refs/notes/commits`, `git log --show-notes=commits -1`, final Git status and
a bounded backup. Keep private lineage/notes out of public packages. Report exact
acceptance limits and unfinished work. Publish only with corresponding authority.
